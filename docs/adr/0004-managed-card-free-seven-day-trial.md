# Bring back a managed, card-free 7-day trial with 50 trial minutes

On 12 October 2026 the public free trial was removed from the ads pages in favour of a teardown and then a "Get your AI receptionist" form. On 14 October Saeed reversed that: the ads pages lead with a free trial again. We chose a managed trial (Brackstone reviews each trial request and sets the receptionist up) over self-serve, because the receptionist only works once it is set up for the business, and screening each request limits wasted setup time on a card-free offer. The trial runs 7 days from go-live, not from the request, so setup time never eats into it, and stops at 50 trial minutes so heavy users cannot run up cost. It is card-free, so it never converts automatically; the business upgrades by choice, and the setup fee is waived if it does so during the trial or within 48 hours of it ending (widened from the 48-hour window alone by Saeed on 14 October 2026, so that the fastest deciders are never charged more).

## Consequences

- The primary conversion is still a trial request submitted on the dashboard (ADR 0003), so ads pages link to the dashboard's trial request page and the site's get-started form stops being the trial path.
- The dashboard needs a 7-day, 50-minute trial shape alongside its existing 14-day managed trials and the garage founding offer.
- Nurture sequence emails must be chosen by trial events (forwarding confirmed, calls answered, minutes used), which the dashboard has to record.
